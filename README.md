# Meet2Go

Plataforma para descubrir eventos y comprar tickets. Proyecto full-stack con backend Node.js/Express y frontend Flutter.

## Estructura del Proyecto

```
Meet2Go/
├── backend/          # API REST con Node.js, Express y PostgreSQL
├── eventos_app/      # Aplicación móvil Flutter
└── README.md         # Este archivo
```

## Instrucciones de Inicio

Para comenzar con el proyecto, sigue estos pasos en orden:

1. **Lee el README del Backend:**
   - Abre `backend/README.md`
   - Sigue las instrucciones para configurar y ejecutar el servidor API

2. **Lee el README del Frontend:**
   - Abre `eventos_app/README.md`
   - Sigue las instrucciones para configurar y ejecutar la aplicación móvil

## Uso de IA en el Desarrollo

Este proyecto utilizó herramientas de IA de forma asistida durante el desarrollo. Para conocer los detalles específicos del uso de IA, consulta el archivo **`AI_LOG.md`** en la raíz del proyecto.

La IA se utilizó principalmente para:
- Generación de estructura base de pantallas
- Configuración de temas y estilos
- Revisión y sincronización entre backend y frontend
- Documentación y comentarios en el código

Todo el código fue revisado, ajustado y validado manualmente para asegurar calidad y coherencia.
